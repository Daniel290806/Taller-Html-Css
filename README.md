Taller HTML y CSS

Descripción

Este proyecto consiste en crear una página web utilizando HTML y CSS, aplicando estilos para mejorar su apariencia y presentación.

Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub

Características

- Encabezado con título y descripción.
- Tarjetas con contenido.
- Diseño adaptable a ventanas estrechas.
- Colores, espacios y bordes personalizados.
- Efecto ":hover" en los enlaces.
